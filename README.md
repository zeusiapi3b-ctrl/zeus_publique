# zeus_publique

Version publique du rapport du projet Zeus (robot autonome à base de Raspberry Pi).

## Voir le rapport en rendu HTML

- Lien direct (le navigateur interprète la page) : https://raw.githack.com/zeusiapi3b-ctrl/zeus_publique/main/rapport_zeus.html
- Remarque : sur GitHub, un fichier `.html` s'ouvre en vue « source » (code brut), ce n'est pas un bug ; utilisez le lien ci-dessus pour le rendu.

## Contenu

- `rapport_zeus.html` : rapport complet en version HTML autonome et statique (aucun script externe, aucun CDN).
- Toutes les informations sensibles (adresses e-mail, adresses IP du réseau local, mots de passe) ont été caviardées.
- Les images du rapport ne sont pas incluses dans cette version publique.
- Le dépôt de développement complet reste privé (dépôt `zeus`).
